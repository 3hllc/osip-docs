# AI

This section specifies AI as a first-class platform capability, including private local and approved cloud inference, context reasoning, privacy boundaries, explainability, evaluation, and model-routing rules. AI is optional at runtime: critical functions retain a deterministic local path without a model.

The [AI Model Deployment Strategy](ai-model-deployment-strategy.md) defines the no-model baseline, private local LLM, and approved cloud-model profiles without selecting a specific vendor or model.
