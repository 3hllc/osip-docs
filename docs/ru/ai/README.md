# ИИ

Этот раздел определяет ИИ как capability первого класса для платформы, включая локальный и облачный inference, контекстное рассуждение, границы конфиденциальности, объяснимость и оценку качества.

Русскоязычная версия сохранит тот же идентификатор, структуру и ссылки, что и английский источник.
