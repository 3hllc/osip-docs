# ИИ

Этот раздел определяет ИИ как возможность первого класса для платформы, включая приватный локальный и одобренный облачный inference, контекстное рассуждение, границы конфиденциальности, объяснимость, оценку качества и правила маршрутизации моделей. AI необязателен во время работы: критические функции сохраняют детерминированный локальный путь без модели.

[Стратегия развёртывания моделей ИИ](ai-model-deployment-strategy.md) определяет базовый режим без модели, приватную локальную LLM и профили одобренных cloud models без выбора конкретного вендора или модели.

Русскоязычная версия сохранит тот же идентификатор, структуру и ссылки, что и английский источник.
