# Продукт

Продуктовые документы превращают стратегию в ограниченные и проверяемые инкременты. Для каждой функции или поставки определяются целевой пользователь, проблема, поддерживаемый объём инсталляции, пользовательский путь, влияние на конфиденциальность и безопасность, non-goals, критерии приёмки, владелец, путь поддержки и связь с относящимися ADR.

Первый продуктовый контур - Installer Edition: квалифицированный инсталлятор может развернуть и сопровождать поддерживаемую local-first инсталляцию без недокументированных знаний основателей. Результаты референсной квартиры становятся требованиями к продукту только после обобщения и проверки.
