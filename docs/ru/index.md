# База знаний OSIP

Этот репозиторий - канонический источник инженерных знаний OSIP. Опубликованный сайт MkDocs является производным представлением; Markdown, диаграммы, ADR, исследования, шаблоны и вспомогательные артефакты в Git остаются источником истины.

## Рабочая модель

1. Определить архитектуру.
2. Зафиксировать значимое решение в ADR.
3. Подготовить относящуюся к нему спецификацию.
4. Реализовать и проверить решение относительно документации.

## Структура

- **Основа** определяет назначение OSIP и неизменные принципы.
- **Стратегия** фиксирует направление продукта, этапы и дорожную карту.
- **Архитектура** описывает модели платформы и сквозные проектные решения.
- **Стандарты** задают правила документации и инженерной работы.
- **База знаний** индексирует проверенные выводы и повторно используемые рекомендации.
- **Совместная работа** описывает, как участники предлагают, рецензируют и поддерживают изменения.
- **Эксплуатация**, **ИИ**, **Продукт** и **Референсные проекты** охватывают соответствующие предметные области.

Для артефактов, которые должны находиться рядом с документацией, есть выделенные каталоги верхнего уровня: `adr/`, `research/`, `diagrams/`, `bom/`, `installer/`, `deployment/`, `templates/`, `scripts/` и `assets/`.
