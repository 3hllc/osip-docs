# Эксплуатация

Эксплуатация делает развёрнутую инсталляцию OSIP поддерживаемой в течение всего жизненного цикла. Для каждой поддерживаемой службы и интеграции определяются владелец, сигналы здоровья, пороги оповещений, журналы и аудит, область резервного копирования, тест восстановления, метод обновления, поведение rollback и путь доступа авторизованного оператора.

Приоритеты эксплуатации - локальная доступность критичных функций, видимые деградированные состояния, безопасное восстановление, диагностика с учётом конфиденциальности и пакет передачи, которым инсталлятор может пользоваться без археологии репозитория. Исполняемые определения развёртывания и пошаговые runbook находятся в `deployment/`; этот раздел определяет ожидания от их эксплуатации.
