# База знаний

Здесь индексируются проверенные, долговечные знания, не относящиеся к одному продукту или архитектурной спецификации. Исходные исследования остаются в `research/`; этот раздел суммирует и связывает принятые выводы.

Раздел также управляет известными неизвестными проекта. [Открытые вопросы](open-questions.md), [Допущения](assumptions.md), [Ограничения](constraints.md), [Риски](risks.md) и [Журнал решений](decision-log.md) рассматриваются совместно, чтобы вопрос, допущение, риск и принятое решение не смешивались.
