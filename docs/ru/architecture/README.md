# Архитектура

Этот раздел описывает платформу до реализации. В нём находятся системные модели, сквозные аспекты и спецификации, ограничивающие работу с ПО, оборудованием, облаком, edge-компонентами и Installer Edition.

Спецификация [Zigbee Mesh и MQTT-мост](zigbee-mesh-and-mqtt-bridge.md) отделяет физическую Zigbee-сеть устройств от MQTT event backbone OSIP и определяет границу их адаптера.
