# Стратегия

В этом разделе зафиксированы решения, ведущие OSIP от референсной квартиры через Installer Edition и коммерческие внедрения к более широкой платформе.

Русскоязычная версия сохранит тот же идентификатор, структуру и ссылки, что и английский источник.
