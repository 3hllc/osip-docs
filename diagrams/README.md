# Diagrams

Store editable diagram sources here, using PlantUML or Mermaid by default. Documentation pages should link to or embed these canonical sources rather than maintaining copied diagrams.

- `c4-system-context.puml` — C4 Level 1 boundaries and external systems.
- `c4-container-view.puml` — C4 Level 2 logical runtime containers.

PlantUML is the canonical source for C4, component, deployment, infrastructure, network, and package views. Mermaid is used for processes, sequences, states, journeys, and simple conceptual models in Markdown.
