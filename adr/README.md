# Architecture Decision Records

ADRs are the canonical record of significant decisions. Create new records from [ADR-template.md](ADR-template.md), number them sequentially, and do not rewrite accepted historical decisions; supersede them with a new ADR when necessary.

The current core records are ADR-0008 (integration providers and canonical boundary), ADR-0009 (semantic bus with transport selection deferred; supersedes ADR-0004), ADR-0010 (physical asset identity and capabilities), ADR-0011 (edge runtime for critical local execution), ADR-0012 (separate intent, policy, and execution), and ADR-0013 (constrained spatial reasoning layer).
